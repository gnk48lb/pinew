# 第 4 轮（round4）

第 3 轮除了出结果，还暴露了“尺子”本身的毛病（agent 会去读隐藏测试和参考解、几次正常操作被误判成篡改、安全闸误拦了一些无害命令、难题太容易）。
评测台升到了 v0.3，安全闸升到了 v1.2，这一轮用修好的尺子把问题重测一遍。判据已在路线图文档的 “round4” 一节里先写死，数据出来之前不改。

要回答的问题：

1. 修好之后的整套 v1（v1.2），比空白基线是不是更省轮数和成本、没有变差？（开发题：8 题 × 3 次，基线和 v1 各跑两批，用来量噪声）
2. 在更难的题上，v1 会不会变差？（6 道难题，基线和 v1 各一批）
3. 如果 v1 不干净，是 AGENTS.md 还是扩展的问题？（两个消融批：只带 AGENTS.md / 只带扩展；先一起跑完，免得再多开一轮）

## 怎么跑

```bash
cd ~/pi && tar xzf pi-round4.tgz && cd arena
bash ../round4.sh              # 先看计划不运行：bash ../round4.sh --plan
```

* 全程不需要输入。8 批、180 次运行，大约 **2.5–3 小时**（开发题每次不到 1 分钟，难题 1–2 分钟）。
  可以睡前开跑，第二天看。
* 开跑前把电脑的睡眠设成“从不”（Windows 设置 → 系统 → 电源），屏幕可以关。电脑睡眠会让正在跑的那次超时。
* 想让它在关掉终端后继续：先 `tmux new -s r4`（装了 tmux 的话），再运行上面的命令。
* 中途停了（Ctrl-C、关机、断网）：再运行**同一条命令**，做完的运行会跳过，从断点继续。
* 网关挂了怎么办：连续 3 次拿不到模型的回答，脚本会停下并说明原因（不会把后面几个小时烧在一个坏网关上）；
  确认网关恢复后运行**同一条命令**，受影响的运行会自动重做。偶发的单次失败，脚本在该批做完后自己补跑（最多 2 轮，间隔 60 秒）。

## 开头会先做三件事（不花 token）

1. **清旧明文**：`arena.py seal --prune`。以前的版本把隐藏测试和参考解以明文放在 `tasks/*/hidden/`、`tasks/*/_ref/` 里，解压新包不会删掉它们；
   新包里它们已经封成 `sealed.dat`，这一步把旧的明文文件夹删掉，只留封存的。
2. **查沙箱**：`arena.py sandbox`。显示你的内核有没有 Landlock，以及哪些路径会对 agent 关闭（arena 文件夹、`runs/`、别处的 arena 副本、`~/pi` 里的 `*.tgz` 压缩包）。
   你的 WSL 内核（6.6.87.2）应该支持（预计是 ABI 3）。如果不支持，脚本会打出原因并**继续**跑，只是偷看过评测文件又做对的运行不会算通过；这时请把那行 WARNING 告诉我。
3. **查题**：`arena.py tasks --check --tasks all`，约 3–5 分钟；通过后留下标记文件 `.round4-taskcheck-ok`，下次续跑就不重做了（删掉它可以重做）。

任何一步失败，脚本会在一个 token 都没花之前停下，把输出整段复制给我就行。

## 里面有什么

```
arena/                评测台 v0.3：沙箱、封存题库（tasks/*/sealed.dat）、偷看检测、受保护文件分两类、r4_scan.py（只读扫描）
v1/                   v1.2 配置包（安全闸不再拦“变量清理、cd 进 /tmp 再删、文本里写着 rm -rf”这类无害命令）
variants/v1-agents/   消融：只有 settings.json + AGENTS.md
variants/v1-ext/      消融：v1 去掉 AGENTS.md（扩展、提示模板、隐藏技能、预设都在）
round4.sh             一条命令跑完所有批次
```

解压会覆盖 `~/pi/arena` 里的代码和题库、`~/pi/v1`、`~/pi/variants/v1-agents` 和 `~/pi/variants/v1-ext`；
你之前的 `configs/`、`runs/`、`day1/`、`suite/` 和结果文件不动。（`~/pi/variants/v1-fid` 这一轮用不到，留着不碍事。）

## 跑完之后发什么给我

脚本最后几行会列出文件名，都是纯文本、没有密钥：

* `arena-results-<时间>.txt`：每个阶段一个（阶段 1：6 批开发题，约 1.7 小时后出现；阶段 2：2 批难题，再约 0.8 小时后出现）。每个文件一出现就可以先发给我，不影响脚本继续跑。
* `r4-scan.txt`：全程结束时自动生成的扫描报告——被安全闸拦下的命令全文、有没有去看评测文件、对受保护文件的改动、预算守卫的记录。

如果脚本中途停下，它也会把已经做完的部分打包，并列出文件名。
