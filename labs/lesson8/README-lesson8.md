# 第 8 课：子代理（delegate），和摘要会不会丢事实

主会话自己读一个大文件，这份文件就留在历史里，之后每一句都要把它再发一遍（按缓存读价算）。
子代理的做法：开另一个 pi 进程去读，只把它的回答带回来，主会话的历史里只多几行字。

这一课测三件事：
1. **钱**：子代理的固定开销是多少，后续每一句少付多少，几句回本。
2. **摘要会不会丢事实**：子代理带回来的回答（和第 7 课的压缩摘要）都是有损的。之后问一个总结里没写的细节，主会话答得出来吗？
3. **子代理的账**：官方示例不把子进程的用量交给 pi，pi 自己的费用显示会漏掉这一笔；交了就进总数。

预测和判定规则已经写在路线图 11-19 那一行里（数据出来之前）。

## 你要做的（10–20 分钟，几乎全是等）

```bash
mkdir -p ~/pi && cd ~/pi && tar xzf <下载的>/pi-lesson8.tgz     # 得到 ~/pi/lesson8/
mkdir -p ~/pi-practice/l8 && cd ~/pi-practice/l8
python3 ~/pi/lesson8/delegate_lab.py --dry-run                   # 不调模型，先看一遍
```

看完 dry-run 之后、正式跑之前，写下两个猜测（随便一句话）：
- (a) 子代理读完之后，主会话后面每一句的钱，比“自己读”的那种少多少？（大概几分之一？）
- (b) 之后问一个总结里没写的细节，用子代理的那一臂答得出来吗？

然后正式跑（28 次运行，约 10–15 分钟，预计 $0.04–0.15，默认花费上限 $0.40）：

```bash
python3 ~/pi/lesson8/delegate_lab.py 2>&1 | tee -ia ex8.log
```

跑完把 `ex8.log` 发给我，再加上：两个猜测，和“最意外的一点”。

## 它会做什么、不会做什么
- 每次运行：脚本现场生成一份约 32KB 的 incident.log（里面藏四个值，每次都不同），一个 pi 进程按顺序收 5–8 句话。四个臂：自己读（R）、只能委派（D，它没有 read 工具）、自己读加填充句不压缩（C0）、自己读加填充句并在第 3 句后强制压缩（C1）。
- 第一次先跑一个预检（子进程能不能起来、用量有没有交出来）；没过会直接告诉你，不会白花钱。
- 你自己的 `~/.pi/agent` 一个字不动：脚本在 /tmp 下起私有目录，放 models.json、auth.json 的副本和实验用的 settings.json，跑完删除。
- 实验里 `cacheWarming` 关掉，不用会话文件。
- 中途 Ctrl+C 没关系：已经跑完的运行照常汇总（私有目录和子进程会清理掉）。
- 某次运行出错（模型没按要求读文件、压缩没成、超时）会用新的材料重跑，最多 2 次；还不行就记失败，不进统计。
- 别加选项：`--arms`、`--reps`、`--model`、`--timeout`、`--no-preflight` 会改设计（我调试用的）。加了以后脚本头会多一行“！用了会改设计的选项”，评分脚本看到这一行就不打分。`--dry-run`、`--max-cost` 随便用。
- 没测的：子代理用别的便宜模型；并行/链式/递归的子代理；比 50KB 更大的文件；隔很久（缓存过期）之后；摘要写得好不好看（只看四个值）；Claude Code 的子代理怎么做的。
