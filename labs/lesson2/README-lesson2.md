# 第 2 课：前缀就是钱

讲义（价目表、请求的排列、会话中途改配置丢多少前缀、你的真实数据、自测题和答案）在手册文档第 2 章。这个包里是练习要用的实验脚本，外加第 1 课 `mini_agent.py` 的更新版。这一课的三个实验是去回答三个我自己还没弄明白的问题（缓存读数的粒度、会话头有没有影响、缓存能活多久），所以你的数据是答案的一半。

## 包里有什么

| 文件 | 干什么 |
|---|---|
| `lesson2/cache_lab.py` | 缓存实验室，只用标准库。三个实验：`api`（直接问网关 9 次）、`pi`（用真 pi 跑 9 次）、`ttl`（缓存寿命，挂机约 65 分钟）。读你 `~/.pi/agent` 里的网关、模型、密钥和价格 |
| `lesson1/mini_agent.py` | 第 1 课那份的更新版，解压时会覆盖旧的。读配置时认 `models.json` 里模型条目自己写的 `api`（第 1 课那份只看 provider 那一层）；遇到它不会说的 `anthropic-messages`，就改走 provider 的入口，并在开头打印一行提示；顺手把价格带出来给 `cache_lab.py` 用。全文 130 行，循环（第 98–121 行）一个字没改，只是后移了 7 行 |

## 解压

```bash
cd ~/pi && tar xzf pi-lesson2.tgz && ls lesson1 lesson2
mkdir -p ~/pi-practice/l2 && cd ~/pi-practice/l2
```

`lesson2` 里应当有 `cache_lab.py` 和 `README-lesson2.md`。

## 练习（10–20 分钟，外加一个可选的挂机实验）

**费用和安全**：`cache_lab.py` 会真的向你的网关发请求，用你 `models.json` 里的价格算花费。三个实验加起来最坏约 3 美分（一个缓存都没命中的情形），一般不到 1.5 美分。每个实验的提示开头都带时间戳，所以“冷启动”一定是冷的，不会被你上一次运行的缓存污染。它不会让模型动你的文件：`api` 实验不带任何工具；`pi` 实验里 pi 带着自己的工具，但每个提示都只要求回一个词，运行目录是 `~/pi-practice/l2`。（`pi` 实验的前 7 个场景为了让前缀可控，没有加载守卫扩展；最后两次默认配置的对比是带扩展的。）

**先猜两个数（30 秒）**：看输出之前，先写下：（a）实验 ① 的第 5 行，只改了系统提示正中间的一句话，命中大约百分之几？（b）实验 ② 的第 6 行，换成一个新会话、提示一字不差，命中高还是低？我的预测已经写进路线图文档的实验日志（11-04–05 那一行），数据一到，对照着看，不改。

**① api 实验（约 1 分钟）**：

```bash
python3 ~/pi/lesson2/cache_lab.py api 2>&1 | tee -a ex2.log
```

直接问网关 9 次，走 OpenAI 接口（和 mini_agent 同一条路）。每行是：总输入 = 新输入 + 命中，命中率，花费（输出也算），下一行是我写的“预期”。看三件事：第 1、2 行的花费差几倍；第 3–6 行命中率怎样随“改在哪里”变化；第 7–9 行（同一个前缀，会话头 甲、乙、甲）有没有变化。

**② pi 实验（约 2–3 分钟）**：

```bash
python3 ~/pi/lesson2/cache_lab.py pi 2>&1 | tee -a ex2.log
```

用真 pi，走 `models.json` 给这个模型指定的那条路（Anthropic 接口）：7 个受控场景（固定的系统提示，开头带时间戳，加约 2k token 的“历史”），再加两次你的默认配置、带与不带 AGENTS.md 的对比。看：第 3–5 行（改系统提示的末尾、中间、开头）的命中是随位置递减，还是三行都一样？第 6、7 行（新会话、不存会话，提示一字不差）命中高不高？最后一段：AGENTS.md 让每个请求多了多少 token。

**③ 缓存能活多久（可选，挂机约 65 分钟）**：

```bash
nohup python3 -u ~/pi/lesson2/cache_lab.py ttl > ttl.log 2>&1 &
```

启动后它大部分时间在等，你可以接着做 ① ② ④。终端窗口要一直开着（关掉 WSL 窗口会把它一起关掉）。随时用 `tail ttl.log` 看进度；想提前收尾，用 `pkill -f 'cache_lab.py ttl'`，已有的结果会打印进 `ttl.log`。想短一点，可以只测三个间隔（约 18 分钟）：

```bash
nohup python3 -u ~/pi/lesson2/cache_lab.py ttl --minutes 1,5,15 > ttl.log 2>&1 &
```

**④ 看一眼启动屏（1 分钟）**：升到 1.5.0 之后你还没看过。`cd ~/pi-practice/l2 && pi`，把最上面那几行抄下来（应当有 [Context] 里的 AGENTS.md，和 [Extensions] 下的三个扩展），然后输入 `/quit` 退出。这一步不会发请求，不花钱。

**⑤ 交作业（1 分钟）**：把 `~/pi-practice/l2/ex2.log` 发给我，加上你的两个猜测和启动屏那几行，再用一两句话说哪一点最意外。`ttl.log` 要等挂机跑完，可以晚一点再补发，不用等它。

## 出了问题怎么办

- 「找不到 mini_agent.py」：先解压（上面第一段命令）。
- 「找不到可以运行的 pi」：先 `export PI_BIN=~/.local/bin/pi`，再重跑。
- 「！网关的 usage 里没有缓存读数字段」：网关的回复里没有“命中”这个数，上面所有的命中就都是 0，不能当真。把脚本最后打印的“原始 usage”那几行发给我。
- 某一行显示「这一行没成功」：后面跟着原因，原样贴给我。其余行不受影响，也可以直接重跑整个实验（每次都换时间戳，不会被上一次污染）。
- ② 最后一段说“两次的总输入没有差别”：pi 没读到 AGENTS.md。先确认第 0 课装好了 v1（`python3 ~/pi/lesson0/install_v1.py --status`），并且是在 `~/pi-practice/l2` 里运行的。
