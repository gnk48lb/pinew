# 第 4 课：规则放哪儿（AGENTS.md、提示模板、技能）

讲义（这三样东西各落在请求的哪一段、各占多少 token、怎么写、怎么读结果、自测题和答案）在手册文档第 4 章。这个包里只有练习要用的实验脚本。这一课要回答两个问题：**你的 pi 每次到底往模型发了什么，其中 AGENTS.md、技能、模板各占多少？** 以及 **同一条规则用三种方式交给模型，它照不照做？** 你的数据是答案的一半。

## 包里有什么

| 文件 | 干什么 |
|---|---|
| `lesson4/rule_lab.py` | 规则放哪儿实验室，只用标准库。读你 `~/.pi/agent` 里的网关、模型、密钥和价格 |
| `lesson4/v1-AGENTS.md` | v1 的 AGENTS.md 的原样副本（8 条）。实验用这一份，不读你自己的 AGENTS.md |

不需要第 1、2、3 课的脚本。

## 解压

```bash
cd ~/pi && tar xzf pi-lesson4.tgz && ls lesson4
mkdir -p ~/pi-practice/l4 && cd ~/pi-practice/l4
```

`lesson4` 里应当有 `rule_lab.py`、`v1-AGENTS.md` 和 `README-lesson4.md`。

## 练习（一条命令，约 10–15 分钟，多数时间在等）

**先猜两个数（30 秒）**：看输出之前，先写下：（a）在你的 pi 里，加 **1 个可见技能** 会让每个请求多几个 token？（b）“skill-good”那条路径，15 次里模型会**自己去读**那个技能几次？我的十四条预测已经写进路线图文档的实验日志（11-08 那一行），在你看到数据之前就锁定了，数据到了对照着看，不改。

**正式跑**（别改次数：我写的评分规则是按每条路径 15 次定的）：

```bash
python3 ~/pi/lesson4/rule_lab.py 2>&1 | tee -a ex4.log
```

分两部分，同一条命令：

**第一部分（约 1 分钟，几乎不花钱）**：用 13 种配置各发 2 个小请求（多数只要一个词的回答），读 pi 自己报出来的“系统提示分段”，再用网关报的总输入 token 做减法，量出：工具、AGENTS.md、一条规则、一个技能清单、隐藏技能、放着的提示模板、调用模板、点名技能，各让每个请求多几个 token。**如果这一部分发现发出去的系统提示不对（屏幕上出现 ✗），或者一个数据都没拿到，第二部分不会开始**：把屏幕上的内容贴给我就行。

**第二部分（约 10–15 分钟）**：同一条规则（commit 信息要以 `[sg]` 开头），用六种方式交给模型：

| 路径 | 规则怎么送到模型 | 次数 |
|---|---|---|
| `none` | 不给规则（对照） | 8 |
| `agents` | 作为第 9 条写进 AGENTS.md（前 8 条是 v1 的原样） | 15 |
| `skill-good` | 放进一个技能，描述写得清楚（`commit-style`）；模型要自己决定去读 | 15 |
| `skill-vague` | 同一个正文，技能名和描述都含糊（`team-notes`） | 15 |
| `skill-cmd` | 隐藏技能，你用 `/skill:commit-style …` 点名 | 15 |
| `template` | 提示模板，你用 `/commit-msg …` 调用 | 15 |

每次运行是一个 pi 进程连问三句：① 写一条 commit 信息（规则靠上面那种方式送到）② 一个无关的问题 ③ 再写一条 commit 信息（这次不再点名、不重复规则）。每次运行时脚本都会读 pi 实际发出去的系统提示，核对它正是这条路径该有的；不对的运行记失败，不进统计。屏幕上每完成一次出一行；跑完会打印几张表，最后是每次运行一行的原始数据。想中途看进度，别关窗口；想停，按 Ctrl+C，已有的结果会照样汇总。

**交作业（1 分钟）**：把 `~/pi-practice/l4/ex4.log` 发给我，加上你的两个猜测，再用一两句话说哪一点最意外。别删最后那段“数据”，我算分用的就是它。

## 费用和安全

- **花费**：用你 `models.json` 里的价格算。预计 0.04–0.10 美元（第 3 课我估高了 10 倍，这次按第 3 课实测的每请求价格折算），花费到 `--max-cost`（默认 0.30 美元）脚本自己停下，并在汇总里说明。
- **不动你的配置**：跑的时候把你的 `models.json`、`auth.json` 复制一份到 `/tmp/rule-lab-xxxx`（权限 600，只有你能读），再放进实验用的 AGENTS.md、技能、模板，跑完整个目录删掉。你真正的 `~/.pi/agent` 一个字不动，你的 AGENTS.md 也不会被读到。
- **只给模型 `read` 工具**：它不能改文件、不能跑命令；运行目录是上面那个临时目录里一个空文件夹。每个 pi 都带着 `--no-session --no-extensions -ns -np`，不存会话、不加载扩展、不自动发现技能和模板。
- **没连过你的网关**：这个脚本我在我这边用一个假网关（一个会按规则行事、能调成“听话”或“不听话”的假模型）加真的 pi 1.5.0 测过（线上字段、系统提示核对、模板和技能的展开、失败重试、超时、Ctrl+C 清理、不动你的配置、解压出来的包本身），但没连过你的真网关。第一次对着真网关跑的是你。

## 选项（一般不用）

`--only anatomy` 只做第一部分；`--only carriers` 只做第二部分；`--arms agents,template` 只测几条路径；`--parallel 1` 一个一个跑；`--model provider/模型id` 换模型。正式跑请不要加这些选项：脚本头一行的“设计指纹”只覆盖脚本里写死的设计（规则、请求、判定标准、各路径的次数），不覆盖你在命令行上加的选项，我算分时按默认设计读。
